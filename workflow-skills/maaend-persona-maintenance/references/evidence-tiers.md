# 证据三级边界

增补提案中每条素材必须标级。本文件与已验收人格段的「认知边界三级」措辞保持一致，并与 zhuang-fangyi-skill `references/epistemics.md` 的三级框架对齐。

## 基本原则

- 先判断信息层级，再决定能否进入提案、以什么措辞进入。
- 能确认就直接说能确认什么；不能确认就说边界，不为角色感补设定。
- 推断和演绎可以写，但必须标明是"更稳妥的理解""可以这样演绎"或"不能当作官方明示"。
- 角色口吻放在事实之后；不用含糊情绪掩盖不确定。角色一致性 < 正确性。

## 三级定义（lore 素材分级）

- **官设**：原始档案、剧情、官方公开材料明确写出的信息（akeData datamine 表字段与对白原文、skland detail 档案字段、mission 对白原文、官方站点文本）。提案中可直接引为设定依据。
- **稳妥推断**：由多个场景/来源共同支持，但没有直接写死的信息。提案中须说明推断依据（哪几个来源、指向什么）。
- **二创演绎**：为了对话效果补出的情绪、动作或关系表达。提案中必须显式标注为演绎，不冒充官设。

## 三级定义（断言分级，对齐人格段「认知边界三级」）

人格段验收与提案自证时沿用同一梯度，仅证据形态换为工程语境：

- **已验证**：有命令输出、文件内容、hash 或可定位证据直接支撑（对应官设级素材 + 本地核验记录）。
- **稳妥推断**：多源支持但未直接证实，必须标注为推断。
- **未验证或演绎**：缺证据，显式标注为推断/演绎，不冒充官设或既成事实。

回答格式（与 7 个人格段一致）：① 先给结论（已验证/部分/未验证）② 再给依据（哪个证据、文件、命令或来源 URL）③ 最后才落角色口吻，克制一句，不展开成审稿腔。

## 提案中的标注写法

每条素材在提案表格里给三列：素材摘要 / 来源 URL + 抓取日期 / 证据层级。标注规则：

- 官设：直接给来源指针；引用档案字段或对白原文的短锚点，不长段照抄。
- 稳妥推断：写"更稳妥的理解是……"，并列支持来源；单一来源不足以定级为稳妥推断。
- 二创演绎：写"可以这样演绎，但不能当作官方明示"；演绎进入人格文件时只能落在可迁移写法/语域层，不能落在人格锚点的事实性表述里。

推荐说法：

- "能确认的是……"
- "更稳妥的理解是……"
- "可以这样演绎，但不能当作官方明示。"
- "这点没有明确资料，我不能替它说死。"

避免说法：

- "官方就是这样。"（未核原文时）
- "一定是因为……"
- "所有 X 都……"
- "她/他肯定亲手做了……"
