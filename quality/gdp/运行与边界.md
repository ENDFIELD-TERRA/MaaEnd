## 类型边界与运行时边界

`proofs/proof-boundary.ts`的私有`defineProof('VerifiedRun')`在可信运行时reader返回数据后，检查授权范围、owner/generation/target、候选build、suite、有效期、实际Passed且无failed/blocked/skipped。类型层再让`buildReviewRecord`要求同一组`Named`的proof，减少诚实调用中拿错对象、构建或套件的错误。

这里的可信reader是**真实集成点**。它必须核验数据来源/认证、artifact→实际进程/target映射、时间、授权scope和原子快照；`runtime-bridge.ts`当前明确抛Pending，不会返回伪Passed。仅仅满足一个结构化JSON对象或把checker返回true，不能证明实验实际执行，也不提供安全授权。`buildReviewRecord`只创建私有审查记录，不发布、不执行控制操作。

原库同kind的proof在运行时是同一个frozen对象，不携带对象身份；proof不能序列化为跨进程授权票据，`name`也不是运行时隔离。候选证明只对读取时刻成立；真正执行动作/发布前仍需真实运行时再次验证current owner/generation和剩余授权，必要时用事务/CAS/租约避免TOCTOU。静态通过、类型反例通过均不能关闭目标业务验收。

## 集成完成后的有界验证命令

在`.qoder/maaend-private/quality/gdp`执行，先盘点同类进程。Node24.19已在当前环境观察到；实际机器须先确认支持源码TS剥离。以下命令不执行上游安装脚本；本轮只执行了第3项原库运行时测试，编译与真实reader验证未运行。

1. 有已审核的预装TypeScript时直接用其`tsc`，无需安装。否则先确认隔离目录内候选`typescript@7.0.2`的发行/integrity和依赖；取得下载许可后生成并审查锁，再`npm ci --ignore-scripts`。MaaEnd主仓不增加依赖。
2. 编译正例和有`@ts-expect-error`的反例，应退出0；编译未标注负例，应非零并包含四个真实类型错误。依赖缺失、命令不存在或解析失败不是预期负例成功。

   ```bash
   timeout --signal=TERM --kill-after=5s 30s node node_modules/typescript/lib/tsc.js -p tsconfig.json
   timeout --signal=TERM --kill-after=5s 30s node node_modules/typescript/lib/tsc.js -p tsconfig.negative.json
   ```

3. gdp原库仅使用Object.freeze与回调，没有网络/文件/进程调用。`upstream-test/runtime.test.ts`是上游四项原始测试，只改import指向保存的源码；本轮整体包组装后执行一次，4通过：

   ```bash
   timeout --signal=TERM --kill-after=5s 30s node --test upstream-test/runtime.test.ts
   ```

   这只证明name传值/异步/freeze和proof singleton语义，不验证候选validator、可信reader或任何MaaEnd功能。所有退出码、stderr和未覆盖边界记录到私有验证矩阵，不能隐去失败。Windows原生用宿主有硬超时的进程API等价执行，不照抄Linux timeout；不得为了它安装WSL。

4. 运行时验证器需要真实reader接通后另验：错误owner/generation/target/build/suite、过期、未来时间、失败/跳过/阻塞报告、残留旧数据及断连都必须拒绝。禁止用默认Pending bridge的抛错充当这些检查已通过。

## 防绕过与采用范围

TS5.4+是库下限，旧5.4/5.5有较晚暴露的名字逃逸诊断。`as`/`any`、ambient declaration、definite assignment、module augmentation等可绕过类型；官方ESLint/Oxlint preset与小trusted模块审查共同约束，仍不是安全沙箱。候选的`vendor/gdp`相对导入若迁移到真实项目，须明确配置`proofImports`，不能假设默认`@gdp-ts/core`导入匹配也覆盖本例。Oxlint JS插件上游标为alpha；不强加给原仓既有lint系统。

仅当实际TypeScript协调层需要这类边界时采用；不把MaaEnd现有Go/Rust/Cpp重写为TS，也不为简单值到处加proof。官方技能`gdp-ts`及完整references可供按需阅读；它要求新增mistakes例子的指导应按用户“先接通、后集中验证”和原仓测试规则执行。
